# گزارش‌ساز تحلیلی سرولوژی — پیاده‌سازی مرحله اول

تاریخ: ۱۸ نوامبر ۲۰۲۶  
شاخه: feature/ibd-first-mvp

## مرجع طراحی
این رابط از قابلیت‌های مستندشده BioChek Monitoring Software (histogram, trend, control tracking)، IDEXX xChekPlus (control tracking by assay/lot) و ID Soft (ورود داده reader/Excel/manual و baseline-aware reporting) الهام گرفته است. این محصول کپی رابط یا الگوریتم هیچ سازنده‌ای نیست.

## اجزای پیاده‌سازی‌شده
- انتخاب مستقل هر نوبت گزارش از پرونده‌های Local-first.
- کارت‌های شاخص: n، میانگین، میانه، SD، CV، Q1/Q3، IQR، دامنه، پراکندگی لگاریتمی، پرچم آماری IQR و BioChek VI در صورت وجود در خروجی ذخیره‌شده.
- هیستوگرام فراوانی و نمودار Box plot؛ پرچم IQR صرفاً برای بازبینی است و نمونه را حذف نمی‌کند.
- نمودار نقطه‌ای برای مشاهده پراکندگی تک‌نمونه‌ها.
- جدول نتایج انفرادی با شناسه نمونه، مقدار، واحد و پرچم آماری.
- نمودار روند فقط در صورت تطابق دقیق گله، روش، کیت، کد، نسخه، ماتریس، آنتی‌ژن، مقیاس، واحد، Lot، آزمایشگاه، Reader و پروتکل، و QC اظهاری قابل قبول.
- پنل QC/provenance که محدودیت QC اظهاری را آشکار می‌کند و ادعای QC خودکار ندارد.
- خروجی CSV نمونه‌ها و چاپ مرورگر/ذخیره PDF.
- نشان صریح داده‌های demo و عدم استفاده بالینی.

## محدودیت‌ها و کارهای لازم پیش از انتشار نهایی
- این مرحله صرفاً report UI است؛ parser واقعی BioChek/IDEXX/IDvet reader یا فایل Excel هنوز پیاده‌سازی نشده است.
- QC خودکار نیازمند OD خام، چیدمان پلیت، کنترل‌های مثبت/منفی/مرجع، محدوده‌های IFU و validation همان کیت است.
- GMT فقط برای scaleهای تیتر مثبت و ratio-scale نمایش داده می‌شود؛ برای OD/S/P/S/N به‌عنوان GMT استفاده نمی‌شود.
- توصیه‌های sample size باید هدف/کیت‌محور باشند؛ عدد ۱۸/۲۳ در BioChek فقط به کاربردهای مشخص راهنمای RevB 2025 مربوط است و قانون عمومی همه کیت‌ها نیست.
- CI سبز، صرفاً صحت نرم‌افزار را نشان می‌دهد و جایگزین validation بیولوژیک/تشخیصی نیست.
- قبل از release باید build و تست کامل روی آخرین commit و آزمون دستی موبایل انجام شود.
