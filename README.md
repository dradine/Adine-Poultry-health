# تصمیم‌یار زمان‌بندی واکسیناسیون طیور آدینه

پروژه‌ای مستقل از سامانه قبلی سلامت طیور آدینه.

## نسخه ۰.۱
- رابط فارسی و راست‌چین
- ورودی تاریخ با تقویم شمسی و ذخیره تاریخ استاندارد در پشت‌صحنه
- پشتیبانی از اعداد فارسی و لاتین
- ثبت محلی مشخصات گله و محاسبه مقدماتی IBD
- اسکیمای اولیه Supabase با تفکیک گله، کیت، واکسن، بچ آزمایش، نتایج و اجرای مدل و سیاست‌های RLS
- service worker برای cache کردن فایل‌های برنامه پس از اولین بارگذاری آنلاین

## اجرای محلی
`npm install` و سپس `npm run dev`. برای ساخت نسخه انتشار: `npm run build`.

## محدودیت علمی
محاسبه‌گر فعلی Deventer-style و آزمایشی است، نه توصیه قطعی واکسیناسیون. فرمول، صدک هدف، BTT و نیمه‌عمر باید با مرجع اصلی، نسخه دقیق کیت و محصول واکسن تطبیق داده و در گله‌های واقعی اعتبارسنجی شوند. نتایج کیت‌های مختلف قابل جایگزینی نیستند. این مدل به ND، IBV یا AIV تعمیم داده نمی‌شود.

## آفلاین و همگام‌سازی
محاسبات در مرورگر اجرا می‌شوند و پروفایل‌های نسخه فعلی در localStorage دستگاه ذخیره می‌شوند. پس از اولین بارگذاری موفق آنلاین، فایل‌های برنامه cache می‌شوند. همگام‌سازی Supabase هنوز به رابط متصل نشده است؛ هیچ کلید service_role نباید در مرورگر قرار گیرد.
